**Project Overview**
---
Superstore Performance Dashboard is an interactive Power BI dashboard developed to analyze sales performance, profit trends, customer segments, payment modes, shipping methods, and regional performance. The dashboard provides a comprehensive view of business operations through dynamic visualizations, KPIs, and filters, enabling users to identify key trends and make data-driven decisions.

The dashboard includes sales and profit analysis across different regions, states, categories, sub-categories, customer segments, and payment modes. Interactive slicers allow users to explore data by region and gain deeper business insights.
